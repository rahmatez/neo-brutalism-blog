# Blog Neo (MDX + Neo Brutalism)

Website blog MDX berbasis Next.js App Router dengan gaya visual `neobrutalism-ui-react`.

## Jalankan

```bash
npm install
npm run dev
```

Lalu buka [http://localhost:3000](http://localhost:3000).

## Konten

Semua artikel diambil dari:

- `content/posts/**/*.mdx`

Frontmatter yang didukung:

- `title`
- `description`
- `date`
- `category`
- `tags`
- `featured` (opsional)
