## Apa itu Linaria?

**Linaria** adalah solusi CSS-in-JS yang mengekstrak style ke file CSS statis saat build time. Tidak ada runtime overhead — performa setara CSS biasa.

<Callout type="tip">
Linaria mendukung TypeScript dan theme tokens, cocok untuk design system yang konsisten.
</Callout>

## Contoh Penggunaan

```typescript
import { styled } from "@linaria/react";

const Button = styled.button`
  padding: 0.5rem 1rem;
  background: #818cf8;
  color: white;
  border: none;
  border-radius: 8px;
  cursor: pointer;
  transition: background 150ms ease;

  &:hover {
    background: #a5b4fc;
  }
`;
```

## Theme Tokens

Blog ini menggunakan centralized theme:

```typescript
export const theme = {
  colors: {
    bg: "#08080d",
    accent: "#818cf8",
    text: "#f1f5f9",
  },
  fonts: {
    sans: "'Inter', sans-serif",
    serif: "'Instrument Serif', serif",
    mono: "'JetBrains Mono', monospace",
  },
};
```

## Keuntungan Linaria

1. **Zero runtime** — CSS diekstrak saat build
2. **Type-safe** — Integrasi penuh dengan TypeScript
3. **Scoped styles** — Tidak ada konflik class name
4. **DevTools friendly** — Class name yang readable
