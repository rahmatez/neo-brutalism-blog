## Mengapa Sandpack?

## Animasi dengan React Spring

Contoh lain menggunakan pola animasi:

```tsx
import { useSpring, animated } from "@react-spring/web";

function FadeIn({ children }: { children: React.ReactNode }) {
  const spring = useSpring({
    from: { opacity: 0, transform: "translateY(20px)" },
    to: { opacity: 1, transform: "translateY(0px)" },
  });

  return <animated.div style={spring}>{children}</animated.div>;
}
```

<Callout type="warning">
Sandpack berjalan di browser client. Pastikan komponen Anda tidak bergantung pada API server-only.
</Callout>
