Memorize shortcut keyboard di Mac bisa menghemat **jam kerja** setiap minggu. Alih-alih menggerakkan tangan ke trackpad atau mouse, jari Anda tetap di keyboard — alur coding jadi tidak terputus.

<Callout type="tip">
Di Mac, tombol utama adalah **Command (⌘)**. Shortcut ditulis `Cmd + K` artinya tahan `⌘` lalu tekan `K`.
</Callout>

| Simbol | Tombol |
| --- | --- |
| ⌘ | Command |
| ⌥ | Option (Alt) |
| ⌃ | Control |
| ⇧ | Shift |
| fn | Function |
| ⌫ | Delete (backspace) |
| ⌦ | Forward Delete |

## Custom Shortcut di macOS

Buka **System Settings → Keyboard → Keyboard Shortcuts**.

### App Shortcuts (buat sendiri)

1. Pilih **App Shortcuts** → klik **+**
2. Pilih aplikasi (misalnya Terminal, VS Code)
3. Masukkan **menu title** persis seperti di menu bar
4. Assign kombinasi tombol

Contoh berguna:

| App | Menu Title | Shortcut |
| --- | --- | --- |
| Terminal | New Tab | `Cmd + Shift + T` |
| VS Code | View: Toggle Terminal | `Ctrl + `` ` |

### Modifier Keys

**System Settings → Keyboard → Modifier Keys** — ubah fungsi Caps Lock jadi Control atau Escape (populer di kalangan vim user).

## Tips Produktivitas Developer

### 1. Pinky di Command, jangan ke mouse

Tiga shortcut paling bernilai:

- `Cmd + Space` — Spotlight
- `Cmd + Tab` — switch app
- `Cmd + P` — quick open file (di editor)

### 2. Pelajari bertahap

Jangan hafal semua sekaligus. Fokus 5 shortcut baru per minggu:

- Minggu 1: sistem (`Cmd + Space`, `Cmd + Tab`, `Cmd + W`)
- Minggu 2: editor (`Cmd + P`, `Cmd + Shift + P`, `Cmd + /`)
- Minggu 3: Terminal (`Ctrl + A/E/R`, `Tab`)
- Minggu 4: window management

### 3. Cheat sheet di desktop

Buat file `shortcuts.md` di home atau pasang wallpaper cheat sheet.

### 4. Raycast menggantikan Spotlight

[Raycast](https://raycast.com) populer di developer Mac — extension untuk Git, Jira, snippet, clipboard history.

| Shortcut | Fungsi |
| --- | --- |
| `Option + Space` | Buka Raycast (default) |
| `Cmd + K` | Actions dalam hasil |

### 5. Clipboard manager

- **Maccy** (gratis, open source): `Cmd + Shift + C` — history clipboard
- **Paste** (berbayar): timeline clipboard visual

## Penutup

Shortcut keyboard di Mac bukan soal hafalan semua kombinasi — tapi **membangun otot memori** untuk aksi yang paling sering Anda lakukan. Mulai dari sistem (`Cmd + Space`, `Cmd + Tab`), lalu editor (`Cmd + P`, `Cmd + /`, `F12`), baru Terminal (`Ctrl + R`, `Tab`).

Investasi satu minggu untuk belajar shortcut akan terasa setiap hari setelahnya — terutama saat debugging, refactoring, dan bolak-balik antara editor, terminal, dan browser.
